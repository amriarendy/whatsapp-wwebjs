## **Whatsapp wwebjs**

**Specification**

- nodejs -v 16.16.0
- php 5.6, 7.1, 7.2, 7.3, **7.4 (recomended)**, 8.0
- MySQL Database
- Apache/Nginx Server

**Dependencies**

```json
    "dependencies": {
	    "axios": "^1.3.4",
	    "express": "^4.18.2",
	    "express-fileupload": "^1.4.0",
	    "express-validator": "^6.15.0",
	    "http": "^0.0.1-security",
	    "mysql2": "^3.5.2",
	    "qrcode": "^1.5.1",
	    "socket.io": "^4.6.1",
	    "whatsapp-web.js": "^1.21.0"
    }
```

**1. Install Dependencies Package**
First one you install node package dependencies

    npm update

or

    npm install

**2. Import Database**
Import database to MySQL Database you can use phpmyadmin, heidiSQL etc.

**3. Run Application**
For running your application type your command

    npm start

or

    nodemon app-whatsapp-single-device.js

**4. Enjoy**
Enjoy your application ☕
